# Keyboard Shortcuts

These are the only shortcuts I care about. I have disabled all
other keyboard shortcuts. If I need anything not here, I will
use the command palette.

## Command Palette
Show: Alt-Cmd-m

## Workspace
Focus Workspace {N}          : Alt+{n}
Move Window to Workspace {N} : Ctrl+Alt+{n}

## Window
Focus Up    : alt+up
Focus Down  : alt+down
Focus Left  : alt+left
Focus Right : alt+right

move up - ctrl+alt+up
move down - ctrl+alt+down
move left - crtl+alt+left
move right - crtl+alt+right

fullscreen - ctrl-alt-enter
native fullscreen - ctrl-alt-cmd-enter
raise float - ctrl-alt-w
toggle float - ctrl-alt-f

### column
left - ctrl-alt-cmd-left
right - ctrl-alt-cmd-right
tabbed toggle - ctrl-alt-t
width +10% - alt-cmd-+
width -10% - alt-cmd-=
balance - ctrl-alt-b
